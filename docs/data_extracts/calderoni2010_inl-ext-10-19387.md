## What this document is

Companion FY-10 hydrogen-only permeability report to
`Humrickhouse2012_INL_EXT_11_23265`. Same INL test apparatus and
candidate alloys (Incoloy 800H, Inconel 617, Haynes 230). Held on
disk for cross-checking the Worst-case (no-oxide) Inconel 617
envelope used in `TritiumPermeationLayer.mo` should the Worst-case
defaults ever be challenged.

Currently no values are transcribed from this report — its role is
backup-of-record. Index entry only.
