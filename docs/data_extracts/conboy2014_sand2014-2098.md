## ⚠️ Source-identity error (2026-05-22) — Conboy2014_SAND2014_2098 retired

Cover-page verification of `~/Downloads/Conboy2014_SAND2014_2098.pdf`
(downloaded 2026-05-21 from `https://www.osti.gov/servlets/purl/1177045`)
revealed the file is **SAND2014-3136**, *"Effects of Increasing Tip
Velocity on Wind Turbine Rotor Design"* by Resor, Maniaci, Berg,
Richards — a wind-turbine blade design report, not a sCO₂ paper.

OSTI biblio metadata for ID 1177045 confirms this:
```
citation_title: "Effects of increasing tip velocity on wind turbine
                 rotor design."
citation_author: Resor, Brian Ray; Maniaci, David Charles;
                 Berg, Jonathan Charles; Richards, Phillip William
citation_technical_report_number: SAND2014--3136
```

The original `_acquisition_log.md` row for `Conboy2014_SAND2014_2098`
keyed the OSTI biblio ID 1177045 to the title and SAND number from a
separate Conboy / Wright / Pasch sCO₂ Brayton cycle paper that the
original logger remembered or saw cited elsewhere. **The biblio ID was
wrong; the title and SAND number stayed.**

OSTI search API (queried 2026-05-22 with `Conboy+Wright+Pasch`,
`Conboy+Pasch+Brayton+SAND2014`,
`Conboy+sCO2+Brayton+performance+characteristics`) returns **no match**
for any Conboy / Wright / Pasch publication titled "Performance
Characteristics of an Operating Supercritical CO₂ Brayton Cycle".
The paper is plausibly a conference paper or SAND number that was
never publicly released to OSTI.
